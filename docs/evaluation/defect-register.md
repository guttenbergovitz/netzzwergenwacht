# Verified Defect and Risk Register

Every entry below was verified directly against the current `rewrite/rust` codebase before being logged.

| # | Defect / Risk | Verified Location | Severity | Validation / Remediation Criteria |
|---|---|---|---|---|
| 1 | **Chromium runs with `--no-sandbox`** | `src/adapters/lighthouse.rs`, `src/adapters/browser.rs` | **Resolved** | Sandboxing is enabled by default; `--no-sandbox` is only passed when `NZW_ALLOW_UNSAFE_BROWSER_SANDBOX=1` is explicitly set (ADR 0006). |
| 2 | **Browser/external tools bypass `TargetPolicy` network rules** | `src/adapters/browser.rs`, `src/investigation/tools.rs` | **Resolved (Chromium CDP) / Planned (Lighthouse/axe)** | `InvestigationScope` (`scheme`, `host`, `port`) is enforced on all `PortableTool` calls and `discover_same_origin_links`; Chromium CDP `Fetch.enable` blocks private/loopback subresources when `PublicOnly`. |
| 3 | **False historical resolutions when checks are skipped/failed** | `src/persistence.rs` (`diff_reports`) | **Resolved** | `diff_reports` classifies missing baseline findings as `unverified_findings` when skipped/unavailable, refuses cross-target comparisons (`not_comparable_reason`), and tracks `changed_findings` (tested). |
| 4 | **Volatile fingerprints & missing page-level scope** | `src/analysis/mod.rs` (`populate_fingerprints`) | **Resolved** | Fingerprints hash `(page_scope, rule_id)` without volatile latency/count prose (tested). |
| 5 | **Unbounded subprocess stdout/stderr & incomplete tree kill** | `src/adapters/mod.rs` (`run_bounded_command`) | **Resolved** | stdout/stderr streams are capped at 16 MiB via `AsyncReadExt::take`; Unix process-group `process_group(0)` + `kill -9 -<pgid>` terminates child trees on timeout/oversize. |
| 6 | **Independent per-collector timeouts instead of shared budget** | `src/main.rs` (`run_check`) | **Resolved** | `run_check` now tracks elapsed wall-clock time via `remaining_audit_budget` across `collect_http` and Level 2 adapters (`lighthouse`, `browser`, `axe`), skipping remaining adapters when exhausted (`run_investigation` already uses `remaining_duration`). |
| 7 | **Quality gates ignore failed/skipped required collectors** | `src/config.rs` (`evaluate_policy`) | **Resolved** | `evaluate_policy` flags `Failed`, `Skipped`, and `Partial` HTTP outcomes and enforces `PolicyConfig::require_collectors` against `AuditReport::level2_collectors` (`browser`, `lighthouse`, `axe`). |
| 8 | **Secret-bearing `Debug` on LLM provider** | `src/intelligence/mod.rs` (`OpenAiCompatibleProvider`) | **Resolved** | Custom `fmt::Debug` redacts `api_key` as `"[REDACTED]"`. |
| 9 | **Unbounded LLM response body & unvalidated AI rule refs** | `src/intelligence/mod.rs` | **Resolved** | LLM response body is stream-capped at 1 MiB and `related_rules` are validated against `AuditReport` rule IDs (`(unverified)` suffix). |
| 10 | **Prompt truncation can produce malformed JSON** | `src/intelligence/mod.rs` (`build_sanitised_prompt`) | **Resolved** | Finding count and field lengths are bounded before JSON serialisation; serialised JSON is never truncated mid-object. |
| 11 | **AI synthesis absent from structured JSON output** | `src/main.rs` (`run_check`), `src/analysis/mod.rs` (`AuditReport`) | **Resolved** | `AuditReport` includes optional `ai_synthesis` (`AiSynthesis` with `JsonSchema`) populated when `--ai` is passed to `nzw check --format json`; `nzw investigate --format json` emits `InvestigationReport`. |
| 12 | **Browser partial load & fallback semantics** | `src/adapters/browser.rs` (`CDP_HARNESS_JS`, `parse_browser_outcome`) | **Resolved** | `CDP_HARNESS_JS` records `load_timed_out` when `Page.loadEventFired` exceeds 15 s and `parse_browser_outcome` emits `CollectorOutcome::Partial` with an explicit warning. |
| 13 | **Incomplete measurement provenance** | `src/domain.rs` (`MeasurementProvenance`, `LighthouseMetrics`, `BrowserEvidence`) | **Resolved** | `MeasurementProvenance` (`viewport`, `throttling_profile`, `origin`, `captured_at`) is attached to both `BrowserEvidence` (via CDP harness) and `LighthouseMetrics` (via `configSettings` and `fetchTime`). |
| 14 | **Batch concurrency & backpressure** | `src/collection.rs:88` (`collect_batch`) | **Accepted Limitation** | `collect_batch` bounds HTTP concurrency via `Semaphore`, but has not yet been stress-tested with Level 2 browser sessions or large target lists. |
