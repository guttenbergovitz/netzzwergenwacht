# Collector Capability Matrix

Inventory of NetzZwergenWacht data collectors, evidence levels, resource budgets, and completeness guarantees.

| Collector | Module | Evidence Level | Default Bounds / Sampling Caps | Truncation / Partial Semantics |
| --- | --- | --- | --- | --- |
| HTTP Collector | `collection::http` | `Source` | `ExecutionBudget` timeout, redirect limit, `max_response_bytes` | `body_truncated` -> `CollectorOutcome::Partial` |
| TLS Inspector | `collection::tls` | `Source` | `ExecutionBudget` timeout | Missing/unverified TLS -> `Skipped` or `Failed` |
| HTML5 Observation Parser | `analysis::document` | `Source` | Single HTML5 parse pass (`visible_text_sample` 4096 B) | Skipped on missing/truncated HTML |
| Discovery & Sitemap Crawler | `discovery` | `Source` | `CrawlBudget` (`max_pages`, `max_depth`, same-origin) | Records `coverage_complete` in `ApplicationGraph` |
| Chromium CDP Harness | `adapters::browser` | `Rendered` | `resources` <= 200, `rendered_images` <= 100, `ax_tree` <= 5000 nodes, 15s load timeout | `load_timed_out` / truncation flags -> `CollectorOutcome::Partial` |
| `axe-core` Adapter | `adapters::axe` | `Rendered` | External CLI invocation bounded by timeout | `Unavailable` when Chromium/axe absent |
| Lighthouse Adapter | `adapters::lighthouse` | `Rendered` | External CLI invocation bounded by timeout | `Unavailable` when Lighthouse absent |
| Source Content Segmentation | `analysis::segmentation` | `Source` | Complete HTTP HTML, 32,768 nodes, depth 128, 256 paragraphs, 4 KiB per paragraph, 128 bytes per language attribute | Tree and paragraph limits explicit. A missing or ambiguous main landmark leaves word distribution unavailable. |
| Browser Runtime and Network Timeline | `adapters::browser` | `Rendered` | Existing Chromium session, 512 events, 128-byte identifier fields, 16 events per query | Explicit event cap and load termination, optional timestamps and correlation. Older snapshots have no timeline. |
| Rendered DOM Segmentation | `adapters::browser` | `Rendered` | Main-frame light DOM at the desktop viewport, 16,384 node visits, depth 64, 256 blocks, 512 UTF-16 units per excerpt. Identity census adds up to 16,384 node visits and counts IDs of up to 128 UTF-16 units | Explicit traversal, retention and census limits. Complete CSS-visible text can carry a versioned fingerprint. Failed evaluation is unavailable. |

## 2. Collector Expansion Priorities (Operation Aufrüstung IV)

Rule-count expansion is frozen at 235 rules while collection depth and typed evidence query APIs are expanded.

| Capability Area | Current State | Priority | Target Wave | Planned Sensory & Query Extensions |
| --- | --- | --- | --- | --- |
| Runtime & Network Timeline | 512 events, request ID, redirect hop, origin, HTTP status, runtime error kind, timestamp | P0 | IV-A2 | Normalised/redacted endpoint paths, initiator stack top frame, interaction correlation, per-request timing phases (DNS/TCP/TLS/TTFB/download), encoded/decoded sizes, wire-level status (`304`), cache source (memory/disk/SW), block/CORS reasons, WebSocket/SSE/frame/SPA route lifecycles, filtered queries |
| Evidence Query Engine | Single-page (16 events) offset reads for source paragraphs and browser timeline | P0 | IV-A2 – IV-H | Typed snapshot queries (`query_network_events`, `query_failed_dependencies`, `query_request_chain`, `query_interactive_elements`, `query_interaction_trace`, `query_application_state`, `query_content_blocks`, `query_element_geometry`, `query_accessibility_nodes`, `query_cookie_inventory`, `compare_consent_sessions`, `query_business_entities`, `find_shared_dependencies`, `find_similar_pages`, `find_similar_components`, `compare_observations`, `query_historical_evidence`, `request_additional_measurement`) |
| Interactive Element Inventory | Aggregate control counts and bounded focus probes | P0 | IV-B | Element-level inventory covering stable identity, tag/role/accessible name, state (`enabled`/`disabled`/`expanded`/`selected`), visibility, bounding box, interaction capabilities, navigation targets, form constraints, ARIA relationships, surrounding context, safety classification, and functional control types (menus, search, filters, pagination, forms, dialogs, tabs, etc.) |
| Application State | No dedicated state model | P0 | IV-B | Shared state observations: document readiness, navigation state, DOM mutation rate, structural/visible fingerprints, active dialog/element/tab, expanded/disabled controls, form validation, loading/error/empty states, scroll position, active filters/variants, network idle state, and stability |
| User Journey & Interaction | Tab, Escape, and bounded skip-link activation | P0 | IV-B | Candidate journey discovery, safe bounded execution (explicit authorisation for state-changing actions), initial/final state comparison, response latency, DOM/AX mutations, route changes, correlated network/runtime failures, repeatable post-remediation verification |
| Visual Geometry | Viewport-level aggregates and basic image dimensions | P0 | IV-C | Element-level bounding boxes, box model, scroll/client dimensions, clipping bounds, text-fragment rects, occlusion/overlap relationships, stacking context (`position`, `z-index`), hit testing, and comparable multi-viewport measurements (prerequisite before re-enabling content clipping rules) |
| Accessibility Tree & Behaviour | 5 summary counters in `AccessibilityTreeSummary` and rule-level `AxeViolation` counts | P0 | IV-C | Per-node AX inventory (node/backend DOM IDs, tree hierarchy, role, name/description with computation sources, states, properties, ignored reasons, relationships, focusability, visibility, geometry), forward/reverse/arrow keyboard flows, focus restoration, modal containment, live regions, zoom/reflow, and element-level `axe-core` evidence |
| Cookie & Browser Storage | 3 counters in `PrivacyStorageSummary` | P0 | IV-D | Cookie inventory (name, domain, path, `Secure`, `HttpOnly`, `SameSite`, `Partitioned`, host-only, session/persistent, expiry, origin, request and consent scenario correlation without raw secret values) and storage inventory (`localStorage`/`sessionStorage` keys, IndexedDB, Cache Storage, service workers, cross-navigation persistence hashes) |
| Consent & External Data Flow | Banner and accept/reject control presence heuristic | P0 | IV-D | CMP identity, available options, isolated multi-scenario observations (`fresh`, `reject_all`, `accept_all`, `custom`, `withdrawal`, `repeat_visit`), observable consent state, storage/network deltas, third-party vendor classification, and choice persistence |
| Performance Attribution | Navigation timings, LCP, aggregate CLS, long-task totals, basic CPU/coverage | P0 | IV-E | LCP sub-parts and resource attribution, CLS session windows and shifting elements, Event Timing (INP breakdown), main-thread task attribution (scripting vs layout/paint), Long Animation Frames, critical dependency chains, font loading, cold/warm cache comparison, JS heap/DOM growth, scenario coverage, and repeated-run distributions |
| Rendered Content & DOM | Bounded main-document paragraphs and landmark regions with SHA-256 text fingerprints | P1 | IV-F | Rendered headings, lists, tables, control/link/label text, product copy, local/inherited rendered `lang`, pseudo-element text, open Shadow DOM, same-origin iframes, CSS vs geometric visibility, heuristic main-content extraction, structural and similarity fingerprints, component association, and cross-page boilerplate clustering |
| Application Topology & Dependency | Page, redirect, canonical, hreflang, and basic resource graph | P1 | IV-F | Observed vs inferred nodes and edges across templates, components, API endpoints, external services, interactions, journeys, business entities, documents, fonts, and application states |
| Structured Business Data | Basic JSON-LD schema validation and entity ID graph | P1 | IV-F | Multi-source extraction (JSON-LD, Microdata, RDFa, semantic HTML, rendered DOM) for products, offers, variants, organisations, locations, articles, contacts, documents, CTAs, and forms, enabling cross-representation consistency checks |
| Search & Discovery | Bounded same-origin crawler, robots sitemap extraction, basic URL classification | P1 | IV-F | Per-agent `robots.txt` model, sitemap provenance and `lastmod` consistency, HTTP/source/rendered canonical and redirect graphs, link context, cross-page fragment validation, hreflang target status, Microdata/RDFa, JS-dependent discoverability, and an explicit crawl frontier/uninspected coverage ledger |
| TLS & Transport | 4 certificate fields in `TlsEvidence` | P1 | IV-G | Certificate chain, SANs, hostname/trust validation, serial, `not_before`, key/signature algorithms and sizes, negotiated TLS version/cipher/ALPN, HTTP/2 and HTTP/3 capabilities, OCSP/CT observations, and optional `testssl.sh` adapter |
| CSS & Component Inventory | Stylesheet transfer metrics and CDP unused CSS bytes | P1 | IV-G | Stylesheet and rule inventory, specificity, duplicate selectors/declarations, custom properties, design tokens (colours, fonts, sizes, line heights, spacing, radii, breakpoints), inline styles, animations, and computed-style/structural component fingerprints |
| Media & Image Binary | DOM image attributes and transfer sizes | P1 | IV-G | Bounded binary inspection (magic bytes/MIME, pixel dimensions, decoded pixel volume caps, aspect ratio, DPR suitability, alpha, animation frames, colour profile, EXIF, exact and perceptual hashes, SVG complexity, video/audio metadata, poster and caption track verification) |
| Historical Evidence & Regression | Finding fingerprints and rendered block text fingerprints (`nzw diff`) | P1 | IV-H | Longitudinal comparison across resource inventories, dependency topology, runtime/network timelines, journey outcomes, application states, performance distributions, AX/cookie/consent/geometry observations, business entities, and collector/profile metadata |
| Document Intelligence | No dedicated document collector | P2 | IV-G | Bounded PDF inspection (format/MIME, byte size, page count, title, language, metadata, text layer, embedded links, outline structure, accessibility tags, fingerprints, and page references) |
| Browser Compatibility | Chromium only | P2 | IV-G | Targeted investigation profiles across engines (Chromium, Firefox, WebKit), device/input/viewport/colour-scheme/reduced-motion emulation, and cross-engine DOM/geometry/journey divergence |
| Field Performance | Laboratory measurements only | P2 | IV-H | Optional CrUX, RUM, and owner-supplied production telemetry kept epistemically separate from laboratory observations |
